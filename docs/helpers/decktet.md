# Decktet support

`src/common/decktet/` — card, deck, and multideck types for Decktet-based games.

## Key types

- `Card`, `Deck`, `Multideck`, `Multicard`
- `cardsBasic`, `cardsExtended` catalogues
- `cardSortAsc`, `cardSortDesc`
