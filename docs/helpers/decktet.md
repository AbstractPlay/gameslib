# Decktet support

`src/common/decktet/` — card, deck, and multideck types for Decktet-based games.

## Key types

- `Card`, `Deck`, `Multideck`, `Multicard`
- `cardsBasic`, `cardsExtended` catalogues
- `cardSortAsc`, `cardSortDesc`

## Example games

- **[Jacynth](https://play.abstractplay.com/games/jacynth)**
- **[Magnate](https://play.abstractplay.com/games/magnate)**
- **[Frogger](https://play.abstractplay.com/games/frogger)**
